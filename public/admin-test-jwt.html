Easy GPT – JWT test page

Use this page to test opening Easy GPT with a JWT token. Paste a token below and click the button. You will be redirected to Easy GPT with the token in the URL; Easy GPT will verify it via the n8n webhook.

For admin team: In your app, when sending the user to Easy GPT, redirect to:
BASE_URL?jwt_token=YOUR_JWT

Replace BASE_URL with the Easy GPT URL and YOUR_JWT with the token you have after user login.
